# 30초 트라이얼 (Trial30)

"죽으면 0.5초 만에 리스타트" — 짧고 굵은 타임어택 레이싱 프로토타입.
Trackmania식 중독 루프: 즉시 재시작 + 자기 고스트와의 대결.

이 프로젝트는 3컨셉 병렬 프로토타입 중 **"트랙 디자인이 주인공"** 컨셉입니다.
순수 웹(HTML + JS + Three.js CDN)만 사용하며, 외부 에셋은 없습니다.

## 실행 방법

- 방법 1: `index.html`을 브라우저에서 바로 열기 (file:// 동작)
- 방법 2: 로컬 서버 권장 — `python3 -m http.server` 후 `http://localhost:8000`
  (localStorage 저장이 file://에서 막히는 브라우저가 있어 서버 실행 시 기록이 확실히 저장됨)

인터넷 연결이 필요합니다 (Three.js r128을 cdnjs/jsdelivr에서 로드, 폴백 포함).

## 조작법

| 키 | 동작 |
|---|---|
| W / ↑ | 가속 (첫 가속 입력에 타이머 시작) |
| S / ↓ | 브레이크 / 후진 |
| A·D / ←·→ | 조향 |
| Space | 핸드브레이크 (드리프트) |
| R | **즉시 재시작** (0.5초 이내, 로딩 없음) |
| 1~5 | 트랙 선택 |
| Esc | 트랙 셀렉트 화면 |

## 트랙 5종 — 각각 하나의 아이디어

| # | 트랙 | 설계 아이디어 |
|---|---|---|
| 1 | A. 스카이 컷 | **점프 컷** — 고속 활주 후 큰 공백구간을 "믿고 직진". 착지 각도가 기록을 가름. 이후 뱅크 스윕과 2연속 부스터로 회수. |
| 2 | B. 부스터 체인 | **부스터 체인** — S자 코너마다 패드가 이어짐. 라인이 어긋나 체인이 끊기면 속도가 무너진다. 패드 배치 = 이상적 라인의 가시화. |
| 3 | C. 나선 강하 | **뱅크 나선** — 고도 60을 뱅크 코너 연속으로 내려옴. 그립을 믿고 풀스로틀로 내달리는 수직 버전. |
| 4 | D. 니들 지그재그 | **좁은 지그재그 + 마지막 롱점프** — 폭 5.5의 니들 구간에서 정밀 조작, 끝에서 부스터 2연타 후 대각선 롱점프로 내던짐. |
| 5 | E. 벨트 서킷 | **입문용 벨트트랙** — 넓은 뱅크 180도와 리듬 부스터로 속도를 유지하는 흐름 학습용. |

모든 트랙은 20~40초 스프린트(포인트 투 포인트)이며, 트랙 밖 추락 = 즉사 = 즉시 리스타트.

## 핵심 시스템 구현

### 즉시 재시작 루프
- 물리는 120Hz 고정 스텝, 렌더는 requestAnimationFrame. 재시작은 **씬/메시를 재사용**하고 차량 상태 변수만 리셋하므로 오브젝트 생성·GC가 전혀 없음 — R 입력 프레임 내에서 즉시 리스타트.
- 사망(추락 감지) 시 자동 재시작, 피니시 후 1.6초 뒤 자동 재시작. 타이머는 첫 가속 입력에 시작(Trackmania 방식).

### 고스트 시스템
- 런 중 매 물리 스텝 위치/요yaw를 60Hz로 decimate 기록 (`ghost.js`).
- 피니시 시 신기록이면 그 런의 기록을 `localStorage`에 저장, 다음 시도부터 반투명 고스트 카로 재생(시간 기반 선형 보간 + 각도 최단경로 보간).
- 저장은 try/catch 래퍼(`util.js`)로 감싸 file:// 제한 등 저장 실패 시 메모리 폴백 — 게임은 항상 정상 동작.

### 트랙 엔진 (`tracks.js`)
- 컨트롤 포인트 → Catmull-Rom 스플라인 재표본화(2유닛 간격) → 노드 배열(위치/접선/은행 각도/폭/부스터/갭 플래그).
- 표면 쿼리가 물리·판정의 단일 진실 공급원: 최근접 세그먼트 투영으로 횡오프셋·표면 높이·부스터·진행도를 한 번에 계산. 공간 해시 그리드로 O(1) 조회.
- 뱅크 코너는 right 벡터의 y성분으로 구현, 점프는 갭 플래그(도로 없음) + 경사에서 얻은 수직속도로 자연 포물선.

### 속도감
- 부스터 패드: 가속 + 상한 62→73 유닛/s 상승 + FOV 펀치(+13° 급팽창 후 감쇠) + 2D 캔버스 스피드라인.
- 점프 중 슬로모션 없음 — 공중에서도 약한 요 제어만 허용해 가속감 유지.

### 사운드 (`audio.js`)
- 전부 WebAudio 절차 생성(외부 파일 0): 엔진 = 노이즈 없는 detuned saw+square (속도 비례 피치/필터), 부스터 = 스윕 blip, 착지/사망/피니시 blip, 신기록 = 4음 상승 팡파레.

## 파일 구조

```
racing-trial30/
├── index.html      마크업/HUD DOM/CSS + 스크립트 로드 순서
└── js/
    ├── util.js     storage try/catch 래퍼, 포맷/수학 유틸
    ├── tracks.js   트랙 5종 정의 + 스플라인 빌더 + 표면 쿼리
    ├── physics.js  아케이드 차량 물리(120Hz 고정 스텝), 사망/피니시 판정
    ├── ghost.js    기록/재생(60Hz 샘플, 보간), 저장 로드
    ├── audio.js    WebAudio 절차 사운드(엔진/부스터/징글)
    ├── world.js    Three.js 씬: 도로 메시/게이트/차량·고스트 메시
    ├── hud.js      HUD 갱신, 트랙 셀렉트 메뉴, 스피드라인 캔버스
    └── main.js     게임 루프/상태 머신/카메라/재시작·고스트 오케스트레이션
```

## 검증

- JS 8개 파일 전부 `node --check` 통과.
- 로직 스모크 테스트(node VM, /tmp/trial30-test/): 5개 트랙 전부 빌드·표면쿼리·고스트 기록/재생 정상.
- 자동 주행 검증(순수추종 오토파일럿, 풀스로틀): 5개 트랙 모두 완주 — A 36.2초 / B 24.9초 / C 33.5초 / D 25.8초 / E 27.6초. 사람이 라인을 잡으면 더 빨라짐.
- 이 과정에서 발견해 고친 결함: 항력 계수 오류(실효 최고속 29로 붕괴), 나선 트랙의 상하층 XZ 겹침 시 잘못된 세그먼트 스냅(쿼리에 높이 대역 필터 추가), 점프 립의 스플라인 오버슛(립 높이 유지점 삽입), 착지지-발사 방향 불일치, 재시작 후 상태 머신 미복귀.

## 알려진 한계
- 브라우저에서의 실행 검증은 이 환경에서 불가(헤드리스 브라우저 미구비) — `node --check` + 노드 기반 물리/트랙 기능 테스트로 대체. 실제 플레이 시 물리 밸런스(그립/점프 거리) 조정이 필요할 수 있음.
- Three.js는 CDN 의존이라 오프라인 file:// 에서는 로드 실패(안내 문구 표시). 폴백 CDN(jsdelivr) 포함.
- 체크포인트는 스펙상 생략 가능 항목으로 미구현 — 대신 "최종 구간 진입 + 도로 위" 조건으로 피니시를 정확히 판정하고, 트랙 밖은 전부 추락사라 단축이 원천적으로 불가능해 판정 무결성을 확보.
- 고스트는 위치/회전만 재생(입력까지는 재생 안 함). 기록은 트랙별 1개(신기록 갱신 시 교체).
- 사운드는 브라우저 자동재생 정책상 첫 키 입력 후 활성화됨.
